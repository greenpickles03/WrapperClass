# WrapperClass Project

A Java project demonstrating the use of **Wrapper Classes**, showcasing how primitive types can be converted to objects, parsed from strings, and used with modern Java features.  
This project is built using **Maven** and follows a clean, professional structure ideal for learning or portfolio presentation.

---

## 🚀 Features

- ✅ Demonstrates autoboxing & unboxing
- ✅ Parsing strings to numeric wrapper types
- ✅ Clean Java package structure
- ✅ Maven project setup (easy to build and run)
- ✅ Beginner-friendly example in `Main.java`
